## ✨ Why This Calculator?

Because normal calculators are boring. This one has **glass**, **gradients**, and actually works on your phone without zooming in like crazy.

### 🎯 What Makes It Different

- **No frameworks** — Pure HTML, CSS, JavaScript. Zero bloat.
- **Actually works on mobile** — Tested on real phones, not just Chrome dev tools.
- **Scientific features** — Not just a basic calculator in disguise.
- **Keyboard shortcuts** — Because clicking buttons with a mouse is slow.

### 🎨 Design
- Glassmorphism with backdrop blur
- Dark gradient background
- Smooth press animations
- Responsive layout (works from 320px to 4K)

### ⌨️ Keyboard Shortcuts

| Key | Action | Key | Action |
|:---:|:---|---:|:---|
| `0-9` | Numbers | `+` `-` `*` `/` | Operations |
| `.` | Decimal | `Enter` `=` | Calculate |
| `Backspace` | Delete | `Escape` | Clear all |
| `%` | Percentage | `p` | Pi π |
| `s` | Square root | `q` | Square |
| `!` | Factorial | `^` | Power |
